# 主题包与数据迁移格式 v1

本文记录任务 10 冻结的 `.cttheme` 主题包与 DataRoot 迁移契约。

## `.cttheme` 主题包

`.cttheme` 是 ZIP 容器，Package Schema 当前为 `1`。根目录只允许以下文件：

```text
manifest.json
theme.json
background.webp
thumbnail.webp   # 可选
```

`manifest.json` 包含：

- `packageSchemaVersion`：主题包格式版本。
- `themeSchemaVersion`：`theme.json` Schema 版本。
- `themeId`：主题 UUID，必须与 `theme.json` 一致。
- `files`：除 manifest 自身外每个文件的相对路径、字节数和 SHA-256。

导出会把受管背景统一命名为 `background.webp`，不会包含绝对路径、日志、
用户身份、脚本、HTML、CSS 或可执行文件。导入完成后图片仍会通过图片安全管线
完整解码并重新编码，而不是直接信任包内字节。

### 导入安全上限

- 压缩包最大 `32 MiB`。
- 解压后总大小最大 `64 MiB`。
- 最多 `16` 个 ZIP 条目。
- 条目只能位于 ZIP 根目录，拒绝绝对路径、`..`、目录分隔符、重复条目和
  非白名单文件。
- 未知的较高 Package Schema 或 Theme Schema 会拒绝导入，且不会覆盖文件。
- 所有条目先写入 DataRoot 下的本次操作暂存目录；文件清单、大小、SHA-256、
  主题契约和背景图片全部验证后才提交主题。
- 导入失败或取消只清理本次创建的暂存目录，不删除现有主题或用户文件。

## 编辑草稿

编辑器从正式主题建立内存草稿。背景选择会生成受管运行图、编辑预览和列表缩略图，
但 `theme.json` 与 SQLite 索引只在用户选择“保存主题”后更新。

- “取消编辑”丢弃草稿参数，不改变正式主题或当前运行主题。
- “保存主题”使用原 UUID 更新正式主题。
- “另存为副本”生成新 UUID，并复制当前草稿引用的受管背景。
- “恢复主题默认值”只恢复可调参数；不会删除背景资源。
- 模拟预览使用自制占位布局，不连接、不嵌入、也不读取 Codex 页面。

## DataRoot 迁移

迁移入口只接受不存在或为空的目标目录，并拒绝与当前 DataRoot 相同或互相嵌套的
路径。迁移顺序为：

1. 桌面端进入忙碌状态，禁用主题写入和切换命令，并创建独占迁移锁。
2. 检查源目录在线且可写、目标父目录可写、目标空间足够。
3. 将数据库、主题、缓存、运行数据和其他 DataRoot 文件复制到本次暂存目录。
4. 按规范化相对路径核对文件数量、总字节数、逐文件 SHA-256 和组合 SHA-256。
5. 以只读、禁用连接池的 SQLite 连接执行 `PRAGMA integrity_check`。
6. 将已验证副本提交到目标目录。
7. 原子替换固定位置的 `bootstrap.json`。
8. 返回目标位置并提示重启桌面应用，使所有长期服务重新绑定新 DataRoot。
9. 原 DataRoot 保持原样，作为恢复副本；应用不会自动永久删除。

若取消、磁盘不足、目标只读、复制中断、指纹不一致或数据库损坏，定位文件仍指向
原 DataRoot。已配置的外置磁盘离线时，应用会 fail-closed 并提示重新连接，不会
静默创建默认空库。

迁移成功报告包含源路径、目标路径、文件数量、总字节数、组合 SHA-256、
SQLite 完整性检查状态、定位文件更新状态和源目录保留状态。

## 便携模式

ADR 0001 当前没有接受 `portable.flag` / `data/` 优先级方案，因此任务 10 不引入
新的便携模式定位规则。若后续需要，必须先通过 ADR 明确它与自定义 DataRoot、
稳定 Agent 路径及持久化提示的优先级。
