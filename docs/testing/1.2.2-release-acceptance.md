# 1.2.2 首次资格超时与持久化升级热修验收

## 修复范围

- 普通运行时操作继续使用 60 秒预算；尚未取得本机资格的 Codex 指纹使用 180 秒首次闭环预算。
- 首次资格超时返回 `Timeout` / `compatibility.qualification_timeout`；用户取消保持 `Cancelled`。
- 已启用持久化时切换主题会先安装当前包内 Agent，确认旧 Agent 在 10 秒内退出后，再原子切换快照、运行时、配置和当前用户 Run 项。
