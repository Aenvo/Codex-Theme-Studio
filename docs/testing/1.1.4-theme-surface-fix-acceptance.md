# 1.1.4 主题表面与阴影修复验收

> 已由 1.1.5 取代：1.1.4 的 Composer 仍带有额外外投影，任务页隐藏背景时也隐藏了侧栏与顶栏后方的透景层。

## 修复范围

- Doro 首页背景保持完整显示，任务页继续遵循主题的隐藏背景模式。
- Composer、下拉浮层和右侧环境面板使用 Doro Panel 色 `#1A151F`。
- Composer 与浮层阴影改用主题中性色，不再保留 Codex 原生灰色高光阴影。
- 左侧快捷跳转栏保持透明，不再被通用 `nav` 规则绘制矩形背景。
- “设为持久主题”对 Doro 可点击；操作只确认现有 OkkSkin 持久状态，不启动第二个 Theme Studio Agent。

## 验证边界

- 自动化覆盖运行时 CSS、主表面恢复、Doro 持久操作与完整构建。
- 真实 Codex 验证只读取样式、几何与运行时状态，不读取或发送对话内容。
- 本次不修改 OkkSkin 的 Run 值、Agent、`state.json`、主题缓存或持久化配置。
- 干净 Windows/VM、有效病毒扫描和完整 Codex 重启仍未覆盖。
