# 1.1.5 任务页框架与 Composer 修复验收

> 已由 1.1.6 取代：1.1.5 移除了 Composer 外投影，但仍保留 Codex 原生 `backdrop-filter`，会在部分 GPU 合成路径下形成外层矩形暗区。

## 修复范围

- Composer 使用 Doro Panel 色 `#1A151F`，仅保留主题 Border 色的一像素轮廓，不绘制外投影。
- Doro 的任务页隐藏模式继续让主内容区使用 `#100D13` 纯色，不把背景图片铺到对话正文下方。
- 任务页继续保留全局 Doro 背景层，使侧栏和顶栏与首页一样呈现半透明透景。
- 右侧浮层和其他高层级表面规则保持不变。

## 本地验证

- Renderer/Main Runtime 定向回归覆盖 Composer 阴影、任务页主表面和任务页背景层。
- 真实 Codex 计算样式验证：Composer 为 `rgb(26, 21, 31)` 且仅有一像素 Border；主表面为 `rgb(16, 13, 19)`；侧栏为 88% 半透明 Panel；顶栏透明。
- 真实任务页截图已目视确认侧栏与顶栏后方显示 Doro 透景，正文区仍保持纯色。
- 短时 Inspector 验证结束后端口 9229 无监听。
- Release 构建 0 警告、0 错误；.NET 测试 137 项通过、2 项现场持久化测试跳过；Node 测试 25 项通过。
- NuGet 直接及传递依赖漏洞扫描未发现已知漏洞。
- 便携目录共 693 个文件、365,917,538 字节，内置 Node.js 为 v24.18.0。
