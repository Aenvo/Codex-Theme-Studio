# 1.1.2 主题显示与持久操作修复验收（已被 1.1.3 取代）

真实首页截图发现 Codex 当前版本的 `main.main-surface` 仍以更高的实际级联优先级遮挡背景。1.1.2 不作为最终验收版本；后续修复与结论以 1.1.3 记录为准。

## 修复范围

- Theme Studio 主题现在覆盖 Codex 当前版本的核心颜色 token，并让首页主工作区透出受管背景层。
- 任务页仍遵循主题声明的 `taskMode`；Doro 的任务页背景保持隐藏。
- 检测到 OkkSkin 持久化时，“设为持久主题”不再全局禁用。
- 选中 Doro 时，该操作确认其已由 OkkSkin 持久化，不会启动第二个 Theme Studio Agent。
- 选中其他主题时，操作给出持久化冲突说明，不会静默修改 OkkSkin。

- .NET：137 项通过；2 项需要显式授权的真实持久化测试跳过。
- Node：25 项通过。

## 边界

- 本次未停用或修改 OkkSkin 的 Run 值、Agent、状态文件或缓存。
- Theme Studio 持久化与 OkkSkin 持久化之间的自动接管仍未实现。
- 真正启用或停用持久化仍需用户对精确状态变更单独确认。
