1. 首页空对话输入框沿用宿主 `--composer-radius`，修复主题背景与毛玻璃四角溢出；保留可见 overflow，避免裁切输入框菜单。
2. 任务对话顶部标题栏透明，去掉额外面板底色、边框、背景模糊与阴影。
3. 定时任务六个推荐卡片跟随面板颜色、透明度及面板毛玻璃效果。
4. 右侧摘要面板以外层统一承载面板色和毛玻璃，分组标题及其伪元素不重复叠加底色。
5. 资料库与插件页面顶部工具栏去掉遮罩伪元素的背景和毛玻璃。
6. 修正主内容边缘裁切、顶部圆角及对话底部重复遮罩。

- 在当前官方 Store 宿主 `26.928.2636.0` 上，通过项目既有的精确进程、创建时间、回环端点、端口所有者及 Browser/Page Target 验证后，只更新当前窗口中的主题 Style。截图复核覆盖首页空输入框四角、任务顶部、六张卡片、右侧摘要分组以及资料库/插件顶部。

- 最后一次 Injector 验证：56 项 Node 测试通过、Injector self-test 通过、`git diff --check` 无错误、9229 无监听。
