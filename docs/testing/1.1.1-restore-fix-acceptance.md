# Codex Theme Studio 1.1.1 Restore 修复验收

日期：2026-07-22

## 根因

1. 1.1.0 的 `renderer-cleanup` 在 Theme Studio 主运行时不存在时提前返回，因此不会清理同一 Codex 进程中的 `__okkskinRJS`、`okkskin-style`、`okkskin` class 和 `--ok-*` 变量。
2. Desktop 只依据 OkkSkin `state.json` 中匹配的 PID 判断 Doro 是否生效。Restore 后该 PID 不会改变，因此界面会同时显示“Codex 官方外观”和“当前外部生效”。

## 修复

- Restore 无论 Theme Studio 主运行时是否存在，都会对可信主窗口清理已知 OkkSkin 运行时；宠物和辅助窗口继续排除。
- Restore 将当前 Codex PID、创建时间和恢复时间写入原子会话状态，用于识别同一进程中的陈旧 OkkSkin PID 记录。
- Doro 卡片在当前进程已恢复后显示“重启后由 OkkSkin 应用”，不再显示“当前外部生效”。
- OkkSkin Agent、Run 值、`state.json`、主题缓存和图片均不修改；Codex 重启后仍由 OkkSkin 恢复 Doro。
- 增加实际 Hook/DOM 状态字段 `knownExternalThemeActive`，供受信运行时诊断与回归测试使用。
