# 1.1.6 Composer 合成暗区修复验收

> 已由 1.1.7 取代：1.1.6 禁用了 Composer 的 backdrop blur，但未移除 Codex 在输入框后方额外绘制的主题色渐变层。

## 修复范围

- 保持 Doro Composer 背景为 `#1A151F`，并保留主题 Border 色的一像素轮廓。
- 禁用 Composer 在不透明主题面板上无视觉收益的 `backdrop-filter`，避免 Chromium 为外层粘性容器创建离屏合成层后产生矩形暗区。
- 不改变 Composer 的尺寸、滚动、焦点和输入交互，也不改变任务页侧栏、顶栏和正文表面的既有规则。

- 真实 Codex 任务页计算样式验证：Composer 为 `rgb(26, 21, 31)`，`backdrop-filter` 为 `none`，外层 768×130 容器保持透明且无阴影。
