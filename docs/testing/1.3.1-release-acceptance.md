# 1.3.1 预览与主题应用稳定性发布验收

## 变更范围

- 编辑器毛玻璃预览改为从统一背景合成层采样，匹配运行时面板透明度，并阻止 WPF 默认模板重复绘制玻璃外框。
- 持久化 Agent 检测同一 Codex 进程已使用其他临时主题时保持让行，直到 Codex 进程重启。
- 可见 Codex 窗口外壳未完成挂载时进入有界 pending 重试，不再报告假成功。
- Agent 停止事件取消正在执行的 Injector；新 Agent 必须稳定取得单实例锁后才算启动成功。
- Desktop 主题写操作会等待启动探测和窗口存在探测结束，避免与 Injector 后台操作并发。
- 主题 Schema、运行时 CSS、持久化配置格式、自更新 API 与三个 Release 资产契约均未改变。

## 未覆盖风险

- 当前没有可用的干净 Windows 用户或 VM；无预装 .NET/Node 环境的启动与完整交互不得写为通过。
- 当前没有有效 Microsoft Defender 服务、实时保护和病毒库；ZIP 与展开目录的有效 Defender 扫描不得写为通过。
- 真实 updater 进程在目录切换期间被终止以及断电边界未覆盖；自动化回滚测试不能替代上述证据。
- 这些缺失项保持 Open。Draft 必须保留公开披露；公开 `v1.3.1` 需要针对本版本的独立风险接受和 Critical 授权。

## 边界

- `v1.3.0` 已具备更新器；只有公开、稳定、非 prerelease、Latest 的 `v1.3.1` 才会被程序内更新发现。
- Draft、构建成功或当前主机验收均不能替代干净 Windows、Defender 或公开端点更新验收。
- Codex 不自动公开 Release，不覆盖既有 tag，不 force-push，也不把未执行项记录为通过。
