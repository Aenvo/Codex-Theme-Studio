# 1.1.3 主题显示与持久操作修复验收

> 已由 1.1.4 取代：1.1.3 未完整覆盖 Composer、右侧环境浮层与快捷跳转栏的颜色和阴影。

## 修复范围

- 主题运行时记录 Codex 主表面的原始 inline 背景，在首页和任务页模式间设置可回滚的受控背景。
- 首页主表面强制透明，受管背景层完整显示；Doro 的任务页隐藏模式仍使用主题背景纯色。
- 核心 Codex 颜色 token 映射到主题 palette；弹层保持不透明以保证可读性。
- “设为持久主题”不再因检测到 OkkSkin 而全局禁用。
- Doro 的持久操作只确认已有 OkkSkin 持久状态，不启动第二个 Agent；其他主题显示冲突说明。

## 自动验证

- 主表面透明/任务页纯色/清理恢复原值均有 Node 回归测试。
- Doro 持久按钮可点击且不会调用 Theme Studio 持久服务有 Desktop 回归测试。
- 完整构建、测试、格式、Agent 与 Injector 自检由本地打包流程执行。

## 安全边界

- 宠物和不完整辅助窗口保持排除。
- 本次不修改 OkkSkin 的 Run 值、Agent、状态文件或缓存。
- 不执行 Theme Studio 持久化 enable/disable 现场测试。
