# 1.3.0 自更新发布验收

## 变更范围

- 新增稳定版更新发现、12 小时缓存和用户强制刷新；后台检查只显示绿色更新图标，不静默安装。
- 绿色图标在资料库、收藏、回收站、设置和编辑器中直接检查更新，不改变当前页面或编辑状态；失败后保留图标供用户重试。
- Release 弹窗显示纯文本说明、下载阶段、进度条和百分比，并对 GitHub 三项资产执行摘要与危险 ZIP 校验。
- 外置 updater 通过同盘目录切换、120 秒健康检查和失败回滚完成自更新；旧清单拥有且未修改的文件才会删除，其他文件进入 `Preserved`。
- 已启用的持久化 Agent 随应用同步升级；失败时继续保留并运行旧 Agent。

- 当前没有可用 Hyper-V、VirtualBox、VMware 或 Windows Sandbox；维护者明确选择不提供额外 VM，并接受 `v1.3.0` 继续 Draft 流程。无预装 .NET/Node 的 Windows 10/11 x64 启动、中文/空格路径、退出和重启没有执行，不得写为通过。
- 本机 Defender 服务、实时保护和病毒库均不可用；ZIP 与展开目录的有效 Defender 扫描没有执行，不得写为通过。
- updater 正常安装、文件锁、健康超时、回滚、未知文件保留、清理失败和 Agent 升级失败由自动化及隔离文件系统覆盖，但不等同于干净 VM 真实安装。

- 上述三项是 `v1.3.0` 的一次性明确风险接受，只允许继续 Draft、人工复核与人工公开流程；README、风险登记和 Release Notes 必须披露。该决定不关闭风险，也不自动放宽后续版本门禁。
