# 任务 12 已知限制

> 历史发布证据：本文对应本地版本 1.0.0；仍适用的限制已汇总到 `risk-register.md`。

## 发布与安全

1. 版本 `1.0.0` 未进行代码签名，Windows 可能显示未知发布者警告。用户必须核对 SHA-256，不应通过关闭安全软件或盲目加入白名单来绕过警告。
2. Microsoft Defender 在验收机上被禁用，本次自定义扫描调用失败；没有获得有效的本机病毒扫描“通过”证据。公开分发前必须在启用且签名库最新的防病毒环境重新扫描。
3. 本仓库当前没有声明面向第一方源代码的开放源代码许可证。第三方许可证只覆盖对应依赖。

## 环境覆盖

1. 最终包已在中文/空格解压路径真实启动，但验收机安装有 .NET SDK 和系统 Node。self-contained 文件、随包 Node 与独立启动均已验证，仍不能等同于无开发运行时的干净 Windows 用户或虚拟机。
2. 本任务运行在当前 Codex 桌面会话内，无法完全退出并重启承载会话的 Codex；因此“Codex 完全重启后由 Agent 恢复主题”没有在本任务中重新执行。修复后的真实 Agent enable/disable、当前 PID 应用和自动化新 PID/PID 复用路径已通过。
3. DataRoot 迁移使用临时真实文件系统和自动化覆盖，没有移动当前用户正在使用的实际 DataRoot。
4. 没有物理删除程序目录来演示清理语义；最终 Run 值、Agent 进程与 Inspector 均已关闭，程序目录与用户数据/稳定 Agent 的位置隔离由实现和文档确认。

## 兼容性

- 当前真实验证的 Codex 版本仍为 Microsoft Store `26.715.4045.0` x64、Electron `150.0.7871.124`。
- 未知版本、非 Store 安装、多个主进程、非回环 Inspector 或不完整主窗口默认 fail-closed。
- Codex 更新即使不改变版本策略记录，也可能改变 DOM 特征；不能只凭版本号声明兼容。
